# Example Marker Map

Genomic coordinates, alleles, and simulated LD-block membership for the
240 columns of \`gs_example_geno\`.

## Usage

``` r
gs_example_marker_map
```

## Format

A data frame with 240 rows and six columns:

- SNP:

  Unique marker identifier.

- CHR:

  Chromosome number (1, 2, or 3).

- POS:

  Base-pair position, increasing within chromosome.

- REF:

  Reference allele.

- ALT:

  Alternate allele counted by the dosage matrix.

- Block:

  Known simulated block identifier, such as \`C1B1\`.

## Source

Generated by \`data-raw/generate_example_data.R\`.
