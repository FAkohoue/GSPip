# Example Genotype Matrix

A simulated additive-dosage matrix for 120 genotypes and 240 biallelic
markers on three chromosomes. Four 20-marker founder-haplotype blocks
are simulated per chromosome. Population-specific founder frequencies
create moderate genomic structure across three populations while
retaining shared founders. One call per marker is missing when the
default settings are used, leaving every marker safely above the default
0.95 call-rate threshold in \`grm_builder.R\`.

## Usage

``` r
gs_example_geno
```

## Format

A numeric matrix with 120 rows and 240 columns. Rows are genotypes
\`G001\` through \`G120\`; columns are marker IDs such as \`S1_0001\`.
Values are 0, 1, 2, or \`NA\`, representing alternate-allele dosage.

## Source

Generated by \`data-raw/generate_example_data.R\` with default seed
20261106.

data(gs_example_geno)

table(gs_example_geno, useNA = "ifany")
