# Example Genomic Relationship Matrix

A ready-to-use additive genomic relationship matrix computed from the
mean-imputed example dosages using the first VanRaden formulation. A
diagonal ridge of 1e-6 is added for numerical positive definiteness.
This object lets the optimization and GBLUP scripts be explored without
first running \`grm_builder.R\`; production analyses should build and
audit their own GRM.

## Usage

``` r
gs_example_grm
```

## Format

A symmetric numeric matrix with 120 rows and 120 columns. Row and column
names are genotype IDs \`G001\` through \`G120\`.

## Source

Generated by \`data-raw/generate_example_data.R\`.

## Examples

``` r
data(gs_example_grm)
dim(gs_example_grm)
#> [1] 120 120
range(eigen(gs_example_grm, symmetric = TRUE, only.values = TRUE)$values)
#> [1]  0.000001 10.552110
```
