# Example Single-Environment BLUE Table

One simulated stage-1 BLUE per genotype for \`gblup_cv_single.R\`. BLUEs
are inverse-variance combinations of the available environment-specific
values. Some \`Weight\` entries are deliberately missing while \`SE\`
remains available, exercising the script's documented \`1 / SE^2\`
fallback.

## Usage

``` r
gs_example_blues_single
```

## Format

A data frame with 120 rows and five columns:

- GenoID:

  Genotype identifier matching the GRM.

- NBL:

  Simulated quantitative-trait BLUE.

- Population:

  Supplied cross-validation stratum (\`P1\` to \`P3\`).

- SE:

  Standard error of the BLUE.

- Weight:

  BLUE precision weight; normally the inverse variance.

## Source

Generated by \`data-raw/generate_example_data.R\`.

## Examples

``` r
data(gs_example_blues_single)
```
