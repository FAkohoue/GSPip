# Example STPGA Candidate IDs

Genotypes eligible for selection by \`optimize_training_population.R\`
in targeted mode. Candidate and target IDs are disjoint and together
cover the complete example GRM.

## Usage

``` r
gs_example_candidate_ids
```

## Format

A one-column data frame with 90 rows. \`GenoID\` contains unique IDs.

## Source

Generated by \`data-raw/generate_example_data.R\`.

## Examples

``` r
data(gs_example_candidate_ids)
head(gs_example_candidate_ids)
#>   GenoID
#> 1   G001
#> 2   G002
#> 3   G003
#> 4   G004
#> 5   G005
#> 6   G006
```
