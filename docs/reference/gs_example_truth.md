# Example Simulation Truth

Known additive and genotype-by-environment marker effects used to
simulate the example BLUEs. This table is supplied for validation and
teaching only. It must not be used to select markers before assessing
prediction on the same phenotypes, because that would leak the simulated
outcome-generating truth.

## Usage

``` r
gs_example_truth
```

## Format

A data frame with 240 rows and six columns: \`MarkerID\`,
\`AdditiveEffect\`, \`GxEEffect\`, \`CHR\`, \`POS\`, and \`Block\`.
Effects are zero for markers not sampled as causal.

## Source

Generated by \`data-raw/generate_example_data.R\`.
