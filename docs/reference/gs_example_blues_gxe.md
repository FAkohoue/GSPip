# Example Genotype-by-Environment BLUE Table

Simulated stage-1 BLUEs for 120 genotypes in three environments for
\`gblup_cv_gxe.R\`. The simulation contains environment mean effects and
moderate genotype-by-environment reranking. Some observed rows contain
only \`SE\` or only \`Weight\`, and six cells have no phenotype or
precision value so that prediction-only rows are represented. Every
genotype remains observed in at least two environments.

## Usage

``` r
gs_example_blues_gxe
```

## Format

A data frame with 360 rows and six columns:

- GenoID:

  Genotype identifier.

- Env:

  Environment (\`E1\`, \`E2\`, or \`E3\`).

- NBL:

  Simulated stage-1 BLUE; \`NA\` for prediction-only cells.

- Population:

  Stable genotype-level stratum (\`P1\` to \`P3\`).

- SE:

  Standard error, possibly missing when \`Weight\` is present.

- Weight:

  Precision weight, possibly missing when \`SE\` is present.

## Source

Generated by \`data-raw/generate_example_data.R\`.

## Examples

``` r
data(gs_example_blues_gxe)
with(gs_example_blues_gxe, table(Env, is.na(NBL)))
#>     
#> Env  FALSE TRUE
#>   E1   119    1
#>   E2   117    3
#>   E3   118    2
with(gs_example_blues_gxe, table(Population, Env))
#>           Env
#> Population E1 E2 E3
#>         P1 40 40 40
#>         P2 40 40 40
#>         P3 40 40 40
```
