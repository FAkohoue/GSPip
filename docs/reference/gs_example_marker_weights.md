# Example External Marker Weights

Non-uniform marker weights for demonstrating the external-weight
interface of \`grm_builder.R\`. The weights are simulated independently
of phenotype and therefore do not introduce trait-based marker-selection
leakage.

## Usage

``` r
gs_example_marker_weights
```

## Format

A data frame with 240 rows and two columns:

- MarkerID:

  Marker identifier matching \`gs_example_marker_map\$SNP\`.

- Weight:

  Finite positive weight sampled between 0.5 and 1.5.

## Source

Generated by \`data-raw/generate_example_data.R\`.

## Examples

``` r
data(gs_example_marker_weights)
summary(gs_example_marker_weights$Weight)
#>    Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
#>  0.5012  0.7646  1.0054  1.0020  1.2322  1.4997 
```
