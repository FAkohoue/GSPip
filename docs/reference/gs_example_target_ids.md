# Example STPGA and Fixed-Split Target IDs

A population-balanced target set for targeted STPGA optimization or
fixed-split GBLUP evaluation.

## Usage

``` r
gs_example_target_ids
```

## Format

A one-column data frame with 30 rows. \`GenoID\` contains unique IDs.

## Source

Generated by \`data-raw/generate_example_data.R\`.

## Examples

``` r
data(gs_example_target_ids)
head(gs_example_target_ids)
#>   GenoID
#> 1   G007
#> 2   G008
#> 3   G009
#> 4   G010
#> 5   G012
#> 6   G014
```
