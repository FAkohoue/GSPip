# Complete Example-Data Bundle

Convenience bundle containing every documented R-native example object.
Loading this dataset creates one list instead of nine separate top-level
objects.

## Usage

``` r
gs_example_all
```

## Format

A named list with nine elements: \`geno\`, \`marker_map\`,
\`marker_weights\`, \`blues_single\`, \`blues_gxe\`, \`candidate_ids\`,
\`target_ids\`, \`grm\`, and \`truth\`.

## Source

Generated by \`data-raw/generate_example_data.R\`.

## Examples

``` r
data(gs_example_all)
names(gs_example_all)
#> [1] "geno"           "marker_map"     "marker_weights" "blues_single"  
#> [5] "blues_gxe"      "candidate_ids"  "target_ids"     "grm"           
#> [9] "truth"         
dim(gs_example_all$geno)
#> [1] 120 240
dim(gs_example_all$grm)
#> [1] 120 120
```
